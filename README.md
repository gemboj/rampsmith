# Rampsmith

A pixel-art color ramp generator: pick a few base colors, shape how their hue, chroma, and lightness shift across a ramp, and get shaded palettes ready to use.

> **Note:** This tool is vibecoded — built almost entirely through conversation with an AI assistant rather than hand-written. The one exception is the logo, which was drawn by hand.

## Background

Rampsmith started as a personal project to help its author get a better intuitive grip on color theory — playing with hue/chroma/lightness curves is a faster way to *feel* how they interact than reading about them. It's also aimed at being genuinely useful for pixel art in gamedev, where hand-picking a clean, consistent shading ramp for every sprite color gets tedious fast.

## Features

- Pick any number of base colors and generate a shaded ramp for each
- Shape Hue, Chroma, and Lightness independently with editable curves (auto or manual handles)
- Multiple shift configurations, assignable per base color
- A color wheel for quickly placing/adjusting base colors
- Share your palette via a URL, or export it as a PNG
